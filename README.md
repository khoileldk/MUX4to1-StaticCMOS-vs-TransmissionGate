# 4:1 Multiplexer Design using Static CMOS and Transmission Gate 

## 📌 Overview

This repository contains a university group project on the design and comparison of 4:1 multiplexers implemented using two CMOS design methodologies:

* Static CMOS
* Transmission Gate (TG)

The work includes schematic design, custom layout implementation, post-layout verification, and performance evaluation of both approaches.

---

## 📋 Project Scope

The project covers:

* 2:1 MUX design
* 4:1 MUX design
* 2-bit 4:1 MUX implementation
* Static CMOS implementation
* Transmission Gate implementation
* Layout design
* Post-layout simulation
* Area, delay, and frequency comparison

---

## 📄 Project Report

The complete project documentation, design methodology, simulation results, layout implementation, and performance analysis are provided in the accompanying report.
